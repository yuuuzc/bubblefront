# 素材方案

原则：**Demo 不依赖任何二进制素材，但保留商业级素材管线**。
所有精灵在启动时程序化绘制进一张图集，所有音效用 WebAudio 实时合成。
要升级成手绘美术时，只替换图集与加载器，渲染代码零改动。

## 1. 美术方向

- 题材：糖果色科幻竞技场。深蓝底 + 高饱和元素色，保证危险信息一眼可读。
- 形状语言：硬砖 = 圆角金属铆钉块；软砖 = 木箱；泡泡 = 玻璃球 + 元素符号。
- 角色：圆胖宇航服小人，护目镜 + 天线队伍灯，四向两帧步行，被困时外套水泡。
- 配色集中在 `src/render/palette.js`：元素五色、队伍四色、区域五色、UI 色板。

## 2. 图集规范

- 单张 **1024×1024**，单元格 **64×64**，帧表为 `name → {x,y,w,h}`。
- 生成器：`src/render/atlas.js` 的 `buildAtlas(rules)`，按数据表自动扩展
  （新增元素/道具会自动获得对应帧位）。
- 帧命名：

| 前缀 | 含义 |
| ---- | ---- |
| `floor0` / `floor1` | 棋盘格地板 |
| `hard` | 永久硬砖 |
| `softA` / `softB` | 软砖两种色差 |
| `bubble_<element>` | 各元素泡泡 |
| `char_<color>_<dir>_<frame>` | 角色四向 × 两帧 |
| `char_<color>_trapped` / `_dead` | 被困 / 幽灵 |
| `item_<powerId>` | 道具图标 |
| `spawn` | 出生点标记 |

- 显示尺寸：地图格 44px，角色按 1.32 格绘制并底部对齐，泡泡带 0.94 格脉动。

## 3. 导出与替换流程

浏览器控制台：

```js
BF.atlas                       // 当前图集
// 导出 PNG 与帧表：
const { atlasToPng, atlasFramesJson } = await import('./src/render/atlas.js');
atlasToPng(BF.atlas);          // dataURL，可存为 atlas.png
atlasFramesJson(BF.atlas);     // 帧表 JSON
```

1. 把 PNG 交给美术，在**相同帧位**上重绘（或改帧表适配新排布）。
2. 用加载器替换 `buildAtlas`：`new Image()` 载入 PNG + `fetch` 帧表，
   返回同样的 `{canvas, frames, cell}` 结构即可。
3. 渲染器、`frameOf`、HUD 全部不用动。

## 4. 动画与特效

- 角色步行：两帧 8 tick 交替；朝向决定眼睛偏移。
- 泡泡：随引信缩短提高脉动频率与辉光，外圈引信圆弧，最后 25% 变红。
- 热区：加法混合径向渐变 + 闪烁；霜面/气域/蒸汽各有独立绘制。
- 特效层 `src/render/fx.js`：粒子、扩散环、飘字、连锁/反应横幅、屏幕震动、
  命中停顿（hit-stop，暂停模拟 4–5 帧，不影响回放确定性）。
- 全部特效只读模拟事件（`state.events`），不回写状态。

## 5. 音频

`src/audio/sfx.js`，无采样文件：

| 事件 | 合成方式 |
| ---- | -------- |
| 放泡 | 正弦上滑短音 |
| 爆炸 | 噪声爆发（低通 2200→90Hz）+ 低频正弦 |
| 连锁 | 随层数升调的双音 |
| 元素反应 | 五音琶音 + 宽频噪声 |
| 拾取/救援 | 大三和弦琶音 |
| 被困/爆泡 | 下行音 + 噪声 |
| 冲刺 | 高通扫频风声 |
| 胜利/失败 | 上行/下行琶音 |

背景音乐是 210ms 步进的贝斯 + 稀疏 lead 循环，默认关闭（`N` 或工具栏开启）。
AudioContext 在首次输入时创建/恢复，符合浏览器自动播放策略；静音只动主增益。

## 6. 素材清单与版权

当前版本 100% 程序化生成，无第三方素材、无字体文件、无授权风险。
